# Вероника — персональный Design Desktop

Интерактивное резюме без сборки и внешних зависимостей. Исходники сайта находятся в `dist/`.

- `dist/data.js` — опыт, проекты, роли, описания, контакты и ссылки.
- `dist/app.js` — представления, навигация, поиск, фильтры, окна кейсов и галерея.
- `dist/styles.css` — стилистика, адаптивность, цвета, размеры.
- `dist/assets/` — фотография и изображения из публичного портфолио.
- `dist/cv.html` — отдельная версия резюме для печати / сохранения в PDF через браузер.

Для локального запуска: `python3 -m http.server 4173 --directory dist`. Открыть `http://localhost:4173`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует содержимое `dist/` после каждого push в `main`. Его также можно запустить вручную в Actions → Publish website → Run workflow. Сборка и платный хостинг не требуются.

В настройках GitHub Pages указан домен `vvvipro-cv.site`. Для подключения у регистратора должны быть четыре A-записи `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; CNAME `www` → `vrreznikova02022.github.io.`. HTTPS включается после проверки DNS и выпуска сертификата GitHub.

Изменения в локальных файлах или Figma сами по себе не публикуются: их нужно перенести в `dist/`, сохранить коммитом и отправить в `main`. После этого публикация запускается автоматически. Файл `.openai/hosting.json` относится к прежнему размещению в Sites и не используется GitHub Pages.

## Поведение

Разделы переключаются внутри окна, страница целиком не прокручивается. Содержимое длинного раздела прокручивается внутри окна. Кейсы открываются поверх каталога, поддерживают прямые ссылки `#projects/view`, переход между проектами, Escape, управление фокусом и увеличение изображений. Основное окно можно перемещать за заголовок, свернуть и раскрыть из дока. На телефоне — меню разделов и полноэкранные карточки кейсов.

## Кейсы и колонка дат, версия 6

Длительность работы перенесена в правую колонку под периодом. На телефоне даты и длительность остаются справа; число и единица длительности, месяц и год связаны неразрывными пробелами.

Все окна кейсов центрируются относительно всего экрана с симметричными отступами. Обложка и изображения занимают всю ширину окна и показываются в исходном соотношении сторон без обрезки. «Моя роль», «Задача» и «Что сделано» используют одну сетку, одинаковые заголовки и текст.

Содержимое галерей находится в `dist/project-content.js`. Для каждого проекта можно менять порядок и количество блоков:

```js
view: [
  image('assets/view1.jpg'),
  text('Заголовок', 'Описание задачи или решения.'),
  image('assets/view2.jpg')
]
```

В `view`, `apes` и `crm` между изображениями намеренно добавлены заголовки и короткие Lorem ipsum-описания по просьбе владельца. Одинаковые заглушки доступны в RU/EN. Для новой галереи добавьте ключ проекта в объект `content`. Изображения из этих блоков автоматически участвуют в увеличенном просмотре и навигации.

Проверены центрирование по координатам, одинаковая типографика трёх строк описания, контент RU/EN, увеличение и возврат к кейсу, переход к следующему проекту, 1440/768/390px. В инспекторе кейса разрешены placeholder-data (явно запрошенный Lorem ipsum) и covered-text (проект намеренно перекрывает неактивную фоновую страницу).
