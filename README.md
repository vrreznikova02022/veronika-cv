# Вероника — персональный Design Desktop

Интерактивное резюме без сборки и внешних зависимостей. Исходники сайта находятся в `dist/`.

- `dist/data.js` — опыт, проекты, роли, описания, контакты и ссылки.
- `dist/app.js` — представления, навигация, поиск, фильтры, окна кейсов и галерея.
- `dist/styles.css` — стилистика, адаптивность, цвета, размеры.
- `dist/assets/` — фотография и изображения из публичного портфолио.
- `dist/cv.html` — отдельная версия резюме для печати / сохранения в PDF через браузер.

Для локального запуска: `python3 -m http.server 4173 --directory dist`. Открыть `http://localhost:4173`.

## Поведение

Разделы переключаются внутри окна, страница целиком не прокручивается. Содержимое длинного раздела прокручивается внутри окна. Кейсы открываются поверх каталога, поддерживают прямые ссылки `#projects/view`, переход между проектами, Escape, управление фокусом и увеличение изображений. Основное окно можно перемещать за заголовок, свернуть и раскрыть из дока. На телефоне — меню разделов и полноэкранные карточки кейсов.

## Дизайн и проверка

Основа: Editorial greeting, seed 338279243. Пользовательская идея рабочего стола macOS определяет окна, док и системную типографику. Основные поверхности светлые, фон шалфейный; фотография оформлена как личный снимок. Главный вопрос первого экрана — кто дизайнер, что делает и где посмотреть работы.

Осознанные отклонения от базового навыка: нативный системный шрифт вместо Instrument Sans для кириллицы и ощущения macOS; тени плавающих окон и прозрачный док; крупное имя как заголовок персонального CV. Маленькие подписи относятся к оболочке рабочего стола. В каталоге визуалы частично обрезаются нижней границей прокручиваемого окна — это граница рабочей области, а не перекрытие контента.

Визуальная проверка: 1440×900, 768×1024 и 390×844. Проверены переходы между разделами, фильтр, поиск без результатов и сброс, открытие кейсов, Escape и прямой адрес кейса. Файлы не требуют сборки; синтаксис JavaScript проверяется `node --check`.
